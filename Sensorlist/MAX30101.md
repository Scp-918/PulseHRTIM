# MAX30101 传感器底层驱动开发核心参考

## 1. 通信基础接口 (Communication Interface)
* **支持协议**: I2C 兼容两线串行接口.
* **最大时钟频率**: 400 kHz.
* **7-bit 从机地址**: 0x57 (固定位 B7-B1 为 1010111).
* **8-bit 写地址(`MAX30101_I2C_ADDR_WRITE`)**: 0xAE.
* **8-bit 读地址(`MAX30101_I2C_ADDR_READ`)3
* **: 0xAF.
* **硬件要求**: SDA 为漏极开路，SDA 和 SCL 均需要外部上拉电阻（通常大于 500Ω）.
* **中断引脚 (INT)**: 低电平有效，漏极开路输出，需外接上拉电阻（建议 4.7kΩ）至最高 +5V 电源.

## 4. 状态机与初始化流程 (Initialization Sequence)
1. **设备验证 (Device ID Verification)**
   * 读取寄存器 `0xFF`，确保返回值为 `0x15`。
2. **软件复位 (Software Reset)**
   * 向 `MODE_CONFIG (0x09)` 写入 `0x40` (置位 RESET)。
   * **延时要求**: 轮询读取 `MODE_CONFIG` 直到 RESET 位(Bit 6) 自动清零为 0，即复位完成。
3. **清空 FIFO 缓冲指针 (Clear FIFO Pointers)**
   * 向 `FIFO_WR_PTR (0x04)`, `OVF_COUNTER (0x05)`, `FIFO_RD_PTR (0x06)` 全部连续写入 `0x00` 以清空残留状态。
4. **配置 FIFO (Configure FIFO)**
   * 写入 `FIFO_CONFIG (0x08)`。例如写入 `0x1F` (不平均、开启 RollOver、A_FULL 剩余15个空位报警)。
5. **配置 ADC 及传感参数 (Configure ADC & Timing)**
   * 写入 `SPO2_CONFIG (0x0A)`。例如配置 4096nA量程，100Hz采样率，16-bit分辨率(118us)：写入 `0x25`。*(注意：采样率与脉宽设置存在互相约束，过高的采样率无法配合长脉宽)*。
6. **配置 LED 驱动电流 (Configure LED PA)**
   * 写入 `LED1_PA (0x0C)`、`LED2_PA (0x0D)`。根据需求调整典型值，例如 `0x24` 约等于 12.6mA。
7. **开启硬件中断 (Enable Interrupts)**
   * 向 `INT_ENABLE_1 (0x02)` 写入 `0xC0` (开启 A_FULL 和 PPG_RDY 中断)。
8. **启动工作模式 (Start Sensor Mode)**
   * 向 `MODE_CONFIG (0x09)` 写入所选模式，例如血氧模式 `0x03`。此时芯片正式开始转换。

## 5. 传感参数控制、数据读取与转换逻辑

* **传感模式与参数**
  * **SpO2模式 (0x03)**: 控制 Red 和 IR LED。一个采样周期内包含一次 Red 和一次 IR 脉冲采样。
  * **HR心率模式 (0x02)**: 仅控制 Red LED。
  * **Multi-LED模式 (0x07)**: 可利用 SLOT1(0x11) 至 SLOT4(0x12) 自由编排红外、红光、绿光的激活顺序。

* **数据准备就绪 (Data Ready Trigger)**
  * **判定方式**: INT 硬件引脚触发低电平 或 I2C 轮询 `INT_STAT_1 (0x00)` 的 `PPG_RDY` 或 `A_FULL` 标志位。
  * **清除中断**: 读取对应的中断状态寄存器（例如 `0x00`），或者读取 `FIFO_DATA (0x07)` 自动清除中断引脚低电平。

* **FIFO 读取与数据拼接 (Data Reading & Concatenation)**
  * 必须使用连续读取(Burst Read)，读取 `FIFO_DATA (0x07)` 时寄存器地址**不会自增**，重复读取返回下一字节。
  * 每个通道(Channel) 数据占用 **3 个字节 (24-bit)**。SpO2 模式下一组完整 Sample 包含 6 Bytes (Red 3Bytes + IR 3Bytes)。
  * **位深掩码**: 数据为左对齐 (Left-Justified)，最高有效位恒在 `Bit 17`。
  ```c
  // C 语言拼接示例 (以 18-bit ADC 为例)
  uint32_t raw_data = ((FIFO_DATA[0] << 16) | (FIFO_DATA[1] << 8) | FIFO_DATA[2]);
  raw_data &= 0x03FFFF; // 屏蔽 18 位以上的无用数据
  ```

* **内部温度转换逻辑 (Die Temperature)**
  * 仅用于补偿红色 LED 的波长漂移。
  * **读取步骤**: 向 `TEMP_CONFIG (0x21)` 写入 `0x01` 开始单次转换 -> 等待 `INT_STAT_2` 中的 `DIE_TEMP_RDY` 置位 -> 分别读取 `TEMP_INT (0x1F)` 与 `TEMP_FRAC (0x20)`。
  * **物理量计算公式**: `T(℃) = (int8_t)TEMP_INT + (TEMP_FRAC * 0.0625)`。
