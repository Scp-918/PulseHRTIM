# TMUX1108 开关底层驱动开发核心参考
# 1. 通信基础接口 (Communication Interface)
- **物理接口**: 并行 GPIO 控制 (Parallel GPIO Control)。无 I2C/SPI/UART 寄存器读写机制。
- **控制引脚**: 
  - `EN`: 使能控制 (高电平有效)。当 EN=0 时，所有开关通道断开 (高阻态)。
  - `A0, A1, A2`: 通道选择地址线 (3-bit 寻址，支持 8路输入)。
- **逻辑电平**: 1.8V 兼容逻辑输入。控制引脚支持最高 5.5V 电压，且具备**失效防护逻辑 (Fail-Safe Logic)**，允许在器件未供电 (VDD=0V) 的情况下在控制引脚施加最高 5.5V 电压而不损坏器件。
- **模拟信号路径**: 
  - 双向运行，支持源极 (Sx) 到漏极 (D) 或漏极到源极的信号双向传输。
  - 轨到轨信号支持，输入/输出电压范围为 VSS 到 VDD。

    #define TMUX1108_CTRL_CH_S2_ADDR    0x01 // 选择通道 S2 (001)
    #define TMUX1108_CTRL_CH_S3_ADDR    0x02 // 选择通道 S3 (010)
    #define TMUX1108_CTRL_CH_S4_ADDR    0x03 // 选择通道 S4 (011)
    #define TMUX1108_CTRL_CH_S5_ADDR    0x04 // 选择通道 S5 (100)
    #define TMUX1108_CTRL_CH_S6_ADDR    0x05 // 选择通道 S6 (101)
    #define TMUX1108_CTRL_CH_S7_ADDR    0x06 // 选择通道 S7 (110)
    #define TMUX1108_CTRL_CH_S8_ADDR    0x07 // 选择通道 S8 (111)

    #define TMUX1108_CTRL_EN_ENABLE     0x01 // 芯片使能 (所有通道受 A[2:0] 控制)
    #define TMUX1108_CTRL_EN_DISABLE    0x00 // 芯片禁用 (所有通道高阻断开)
    #define TMUX1108_CTRL_CH_NONE       0xFF // 驱动层约定的全断开掩码

# 4. 状态机与初始化流程 (Initialization Sequence)

- **步骤 1**: 寄存器地址 -> GPIO 时钟使能 (GPIOA/B/C/D)
  - **写入值**: 无特定寄存器值，操作 MCU 对应的 RCC 寄存器。
  - **功能描述**: 开启对应控制管脚的 GPIO 时钟。
  - **延时要求**: 无。
- **步骤 2**: 寄存器地址 -> GPIO 模式配置
  - **写入值**: 配置 A0, A1, A2 及 EN 为推挽输出 (Push-Pull Output, 低速/中速)。
  - **功能描述**: 设置硬件控制引脚方向与模式。
  - **延时要求**: 无。
- **步骤 3**: 寄存器地址 -> 初始状态设置 (Software Reset Equivalent)
  - **写入值**: EN = 0 (若硬件可控), A[2:0] = 000。
  - **功能描述**: 确保上电时所有模拟通道处于高阻断开状态，防止上电瞬间多个信号源短路。
  - **延时要求**: 等待 VDD 电源完全稳定以建立正常的导通电阻。
- **步骤 4**: 寄存器地址 -> 通道切换 (Channel Switching)
  - **写入值**: 按照真值表同时更改 A2, A1, A0 输出电平，并拉高 EN。
  - **功能描述**: 执行先断后合 (Break-Before-Make) 的物理通道切换。
  - **延时要求**: 至少等待 23ns (VDD=3.3V 时的最大切换时间)，系统级驱动建议在启动 ADC 采样前至少加入 1μs 延时以吸收电荷注入和 RC 稳定。

# 5. 传感参数控制、数据读取与转换逻辑

- **参数控制（硬性电气约束）**:
  - **导通电阻 (RON)**: 典型值为 2.5Ω 至 4.9Ω (随 VDD 变化)。在计算高精度 ADC 的前端 RC 驱动电路时，必须将此电阻与源内阻串联计算。
  - **导通漏电流 (ILEAK)**: 极低，典型值为 3pA。适合连接高阻抗传感器（如压电、热电偶）。
  - **电荷注入 (QC)**: 典型值 1pC。切换通道时会在通道上产生微小电荷突变，高精度测量时建议在 ADC 采样前预留充足的稳定时间以吸收此电荷。
- **工作模式与驱动逻辑**:
  - 本身不具备测量模式，物理通路完全受控于 A[2:0] 寻址。任何时刻最多只能有一个源极引脚 (Sx) 物理连接到漏极引脚 (D)。
  - **KB 组（带 EN 控制）**：切换通道时可选用 TMUX1108_CTRL_CH_NONE (拉低 EN) 进行总线完全隔离。
  - **KH / KL 组（无 EN 控制，常开型）**：通道始终连通，驱动中仅能通过变更 A[2:0] 改变所连传感器，无断开所有通道的选项。
- **读取触发与判定**:
  - 芯片仅导通物理模拟信号，无 Data Ready 标志或硬件中断。
  - 读取动作需由后端 ADC（如 ADS8864 或内部 MCU ADC）的定时器或软件独立触发。
  - 必须确保触发采样发生在 TMUX1108 切换完成且信号建立之后。
- **数据拼接与物理量转换**:
  - TMUX1108 对信号无数字转换。数据位深、大小端模式、有符号数（补码）处理均由后端 ADC 的配置决定。实际物理量需根据挂载的传感器特性曲线及 ADC 的 VREF 参考基准进行换算。
